# Manage skills

Open **Settings > Skills** to create, edit, enable, disable, or delete reusable agent instructions.
Choose the environment first through a project, or use the primary environment for global skills.
Global skills apply across projects; project skills belong to the selected workspace.

**Import** discovers existing agent skills on that environment. Select the sources to import and
whether to skip duplicates. Imported skills remain editable in T3 Code. Provider-owned or read-only
skills show their source and cannot be edited or deleted here.

Keep a skill focused on one reusable workflow. Give it a clear name and description so an agent can
recognize when it applies. Enable or disable a skill without deleting its instructions.
