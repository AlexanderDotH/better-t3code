# Interface language

Web, desktop, and mobile offer an interface-language choice under **Settings > Appearance >
Language**:

- **System** follows the preferred language of the current device. German and English system
  locales are supported; other locales fall back to English.
- **English** always uses the English copy supported by T3 Code.
- **Deutsch** always uses the German copy supported by T3 Code.

The selection is available offline and synchronizes through compatible connected T3 environments.
When an environment is disconnected, it receives the selection after reconnecting. The setting
reports environments that failed to update or require a newer T3 server.

The choice currently applies to the language setting itself, memory-protection and provider-throttle
notices, native desktop menus and update dialogs, and app-owned mobile notification and Live Activity
copy. Interface areas that have not yet been localized remain in English.

Provider and agent responses, terminal output, logs, command names and flags, code, Git content, and
machine-readable values are never translated by this setting.
