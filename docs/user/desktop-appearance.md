# Desktop appearance

On macOS, open **Settings → Appearance → Background transparency and blur** to
show the desktop through a tinted, natively blurred window. The setting starts
off, applies immediately, and is remembered for the next launch. Turn it off to
restore solid backgrounds. Text, controls, and code surfaces retain their theme
colors. macOS Reduce Transparency keeps the app surfaces opaque.

This preference belongs to the local desktop app, including when it connects to
a remote, relay, or tunneled environment. It does not change other devices,
browser clients, Windows/Linux desktops, or mobile apps, and works with every
provider. Find it by searching Settings for “transparency” or “blur”; there is no
dedicated command-palette action or keybinding.

**Glass opacity** separately controls overlays inside the app, such as menus,
dialogs, and the composer.
