# Bring existing conversations into T3 Code

Open **Settings → Chat import** to discover supported chat sources on the selected environment.
Choose the sources to import. Importing copies their conversations into T3 Code; it does not move
or delete the originals. Refresh the source list after adding another provider or profile.

For ongoing provider history, open **Settings → Connections → Harness chat sync**. Choose an
environment and source, search its conversations, and select which ones to sync. Include archived
conversations when needed. If a conversation refers to a project that T3 Code does not recognize,
choose its destination project before continuing. Existing linked conversations can be synced again.

Sources belong to the selected environment. A remote environment reads its own provider history,
not the history stored on the device displaying T3 Code. Syncing requires write access to that
environment.
